# HP LaserJet M1212nf MFP — печать и сканирование

Простое приложение для ПК, через которое можно пользоваться МФУ **HP LaserJet Pro M1212nf**
(и его родственниками M1210-серии): печатать, сканировать со стекла и из автоподатчика и
делать копии. Сканы получаются **качественными и лёгкими**: страница A4 весит десятки или
сотни килобайт, а не 100 МБ.

## Возможности

**Сканирование**
- Со стекла (одна страница) или из **автоподатчика** (все листы за раз, до 35).
- Профили качества, все при 300 dpi, кроме фото:

  | Профиль | Режим | Примерный размер страницы A4 |
  |---|---|---|
  | Текстовый документ (Ч/Б) | 1 бит, 300 dpi | **10–60 КБ** |
  | Документ в оттенках серого | JPEG 75, 300 dpi | **150–400 КБ** |
  | Цветной документ | JPEG 75, 300 dpi | 300–900 КБ |
  | Фото (высокое качество) | JPEG 90, 600 dpi | 2–5 МБ |

  Для сравнения: стандартное сканирование Windows сохраняет BMP, это ~25 МБ при 300 dpi
  и ~104 МБ при 600 dpi в цвете.
- Функция «Белый фон» убирает серость и шум бумаги, а текст становится чётче и контрастнее.
  Заодно JPEG становится в 3–5 раз меньше.
- Ползунок сжатия и **оценка итогового размера** прямо в окне. Качество и режим можно
  менять после сканирования, пересканировать не нужно.
- Поворот, перестановка и удаление страниц, обрезка пустых полей.
- Сохранение в **многостраничный PDF**, JPEG, PNG или многостраничный TIFF.

**Печать**
- PDF и изображения печатаются напрямую, без Adobe Reader. Word, Excel и TXT печатаются через
  связанную с ними программу.
- Количество копий, диапазон страниц (`1-3, 5, 8-`), «вписать в лист» или 100 %.
- **Двусторонняя печать вручную.** У M1212nf нет автоматического дуплекса. Приложение
  печатает лицевые стороны, подсказывает, как переложить стопку, и печатает обороты
  в правильном порядке.
- Можно передать файлы при запуске (`app.py file.pdf`), например через «Открыть с помощью».

**Копирование.** Кнопка «Напечатать копию» печатает только что отсканированные страницы.

**Принтер.** Состояние (нет бумаги, замятие, тонер), очередь заданий, очистка «зависшей»
очереди, веб-интерфейс принтера (уровень тонера, сеть), настройки драйвера (EconoMode).

## Установка на Windows 10/11

1. **Драйвер HP.** Установите полный пакет драйверов для M1212nf с
   [support.hp.com](https://support.hp.com) (поиск: `LaserJet Pro M1212nf`). В нём есть
   драйвер сканирования WIA, без которого Windows «не видит» сканер, особенно по сети.
   Если принтер уже печатает, а сканер не находится, значит не хватает именно этого драйвера.
2. **Python 3.10 или новее** с [python.org](https://www.python.org/downloads/). При установке
   отметьте **«Add python.exe to PATH»**.
3. Скачайте папку `hp-m1212nf-app` и дважды щёлкните **`run_windows.bat`**. При первом запуске
   скрипт сам установит зависимости (Pillow, PyMuPDF, pywin32) в локальную папку `.venv`.

**Необязательно:** запустите `build_exe.bat`, и в `dist\HP-M1212nf.exe` появится один
exe-файл, который работает без Python. Его можно положить на рабочий стол.

## Установка на Linux

```bash
sudo apt install hplip sane-utils python3-tk python3-venv
hp-setup -i           # добавить принтер (USB или сеть)
hp-plugin -i          # проприетарный плагин HP, нужен M1212nf для печати
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Проверка сканера: `scanimage -L` должен показать устройство `hpaio:/…`.

## Как пользоваться

**Сканировать документ в PDF:**
1. Вкладка «Сканирование». Положите лист на стекло лицом вниз или стопку в автоподатчик
   лицом вверх и выберите источник.
2. Выберите профиль. Для договоров и справок подойдёт «Документ в оттенках серого»,
   для текста без печатей и подписей — «Текстовый документ (Ч/Б)».
3. Нажмите **«Сканировать»**. Со стекла можно отсканировать несколько листов подряд:
   каждая страница добавляется в конец.
4. Нажмите **«Сохранить…»** и выберите PDF.

**Двусторонняя печать:**
1. Включите «Двусторонняя (вручную)» и нажмите «Печать».
2. Когда лицевые стороны напечатаются, возьмите стопку из выходного лотка, **не
   переворачивая её**, и положите во входной лоток чистой стороной вверх.
3. Нажмите OK. Если обороты получились вверх ногами, включите «повернуть 2-ю сторону
   на 180°». Настройка запомнится.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Сканер не найден | Установите полный драйвер HP (п. 1), перезапустите приложение и нажмите «Обновить список». Для сетевого подключения проверьте, что ПК и МФУ в одной сети. |
| «Сканер занят» | Закройте другие программы сканирования (HP Scan, «Факсы и сканирование»). |
| Печать «зависла» | Вкладка «Принтер» → «Очистить очередь», затем выключите и включите МФУ. |
| Бледная печать | «Настройки драйвера…» → отключите EconoMode и увеличьте плотность. Либо заканчивается тонер (картридж CE285A / 85A). |
| Ч/Б скан теряет тонкие линии или печати | Используйте профиль «Документ в оттенках серого». |

## Устройство кода

| Файл | Назначение |
|---|---|
| `app.py` | Интерфейс (tkinter): вкладки «Сканирование», «Печать», «Принтер» |
| `scan_backend.py` | Сканирование: WIA (Windows) и SANE/`scanimage` (Linux) |
| `print_backend.py` | Печать: GDI (Windows) и CUPS/`lp` (Linux), план ручного дуплекса |
| `image_tools.py` | Очистка фона, бинаризация (Оцу), сжатие, сохранение PDF/JPEG/PNG/TIFF |
| `tests/test_core.py` | Тесты: `python -m unittest discover tests` |

Настройки (профиль, папка сохранения, принтер) хранятся в `~/.hp_m1212nf_app.json`.
